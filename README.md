# Liva Food — Concept Restaurant Website

A fictional restaurant website created as a portfolio project to showcase my web design and front-end development skills.

The concept focuses on a bold, energetic identity for a Middle Eastern street-food restaurant. Oversized typography, strong colors, playful layouts, food photography, and subtle motion work together to create a memorable and modern experience.

## Design highlights

- Bold editorial typography and a distinctive visual hierarchy
- A warm, high-contrast color palette inspired by street-food culture
- Responsive layouts for desktop, tablet, and mobile screens
- Interactive navigation and smooth in-page menu links
- A custom restaurant menu with clearly structured categories and pricing
- Playful hover effects, animations, stickers, and graphic details

## Built with

- Semantic HTML5
- Custom CSS3
- Minimal vanilla JavaScript for the responsive mobile navigation

No frameworks or UI libraries were used. The project was intentionally built from scratch to demonstrate layout, typography, responsive design, and visual storytelling skills.
